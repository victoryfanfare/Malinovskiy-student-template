## 5. Analysis

### 5.1 Сравнение алгоритмов (важные наблюдения)

- **KMeans "ломается"** на dataset-2 из-за нелинейной структуры. Алгоритм пытается разделить данные линейными границами, что неэффективно для "облака" точек с выбросами.

- **DBSCAN выигрывает** на dataset-2 благодаря способности находить кластеры произвольной формы и выделять шум. Однако на dataset-3 он сталкивается с проблемой разной плотности - единый параметр eps не может одинаково хорошо работать для плотных и разреженных кластеров.

- **AgglomerativeClustering** показал лучшие результаты на dataset-1, где иерархическая структура соответствует данным. Ward linkage минимизирует внутрикластерную дисперсию, что хорошо для "шарообразных" кластеров.

- **Масштабирование** оказалось критически важным для всех методов. На dataset-1 без масштабирования признаки с большими значениями полностью доминировали в вычислении расстояний.

- **Визуальная проверка** оказалась не менее важной, чем метрики. Метрики иногда предлагали неоптимальные решения (например, для dataset-2 silhouette максимизировался при агрессивных параметрах DBSCAN, создающих много мелких кластеров).

### 5.2 Устойчивость (обязательно для одного датасета)

- Проверка устойчивости проведена для **dataset-1** с KMeans (k=3)
- Метод: 5 запусков с разными random_state (42, 142, 242, 342, 442)
- Результаты:
  - Средний ARI между запусками: 0.967 ± 0.012 (очень высокая устойчивость)
  - Средний silhouette: 0.543 ± 0.003 (стабильный)
  - Средний inertia: 1278.5 ± 2.1 (минимальные колебания)
- Вывод: KMeans на dataset-1 показывает исключительно высокую устойчивость к разной инициализации. Это свидетельствует о хорошо определенной структуре кластеров и правильном выборе k.

### 5.3 Интерпретация кластеров

- Для dataset-1: Agglomerative с k=3 выделяет три естественные группы, различимые визуально в PCA-пространстве. Кластеры соответствуют разным областям плотности в пространстве признаков.

- Для dataset-2: DBSCAN правильно идентифицирует основную массу точек как один кластер, а периферийные точки маркирует как шум. Это соответствует структуре "ядро + выбросы".

- Для dataset-3: KMeans четко разделяет кластеры, которые видны даже невооруженным глазом. Кластеры различаются по плотности, но KMeans успешно их разделяет благодаря четкой границе между ними.

## 6. Conclusion

1. **Визуальная проверка обязательна** в unsupervised-задачах. Математические метрики могут предлагать неоптимальные решения без визуального подтверждения.

2. **Выбор алгоритма зависит от структуры данных**: 
   - Agglomerative хорош для иерархических структур (dataset-1)
   - DBSCAN отлично справляется с шумом и нелинейными формами (dataset-2)
   - KMeans эффективен для четко разделенных "шарообразных" кластеров (dataset-3)

3. **DBSCAN чувствителен к разной плотности**: когда кластеры имеют разную плотность (dataset-3), подобрать единый eps становится сложной задачей.

4. **Масштабирование критически важно** для всех distance-based методов. Особенно на dataset-1, где признаки были в разных шкалах.

5. **Устойчивость алгоритма** — важный показатель качества кластеризации. Высокая устойчивость KMeans на dataset-1 подтверждает надежность выбранного решения.

6. **Параметры должны иметь смысл**: eps=0.8 для DBSCAN на dataset-2 был выбран как "золотая середина"

7. **Не существует универсального решения**: каждый датасет потребовал своего подхода и алгоритма.

8. **Честный протокол эксперимента** включает не только вычисление метрик, но и визуальную оценку, проверку устойчивости и осмысленную интерпретацию результатов.
